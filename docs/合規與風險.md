# 合規與風險說明

> 本文件是整理給使用者參考的檢查表，原則上不構成法律意見。法規與平台條款會更新，請以最新公告為準，必要時請洽專業人士。

## 這個工具「做」和「不做」的事

| 做 | 不做 |
|---|---|
| 用官方 API 或你自己合法取得的資料，找公開貼文 | 登入帳號用瀏覽器爬網頁 |
| 依規則和 AI 產生「回覆草稿」 | 模擬真人滑動、隨機延遲來躲偵測 |
| 一律由人審核，核准後由人自己回覆 | 養帳號（自動按讚、暖機） |
| 每品牌每日草稿上限 | 繞過驗證碼或登入檢查 |
| 貼文定期自動刪除 | 私訊、加好友、大量洗留言 |

自動發文只能透過另外安裝、預設關閉、只走官方 API 的外掛，而且只送人工核准過的草稿。

## 平台條款檢查表（Threads／Meta）

- [ ] 資料來源是官方 Threads API，或你自己合法匯出／整理的資料。
- [ ] 沒有用自動化工具登入帳號抓資料。
- [ ] 每則留言都跟對方貼文的需求直接相關，不是到處貼同一句廣告。
- [ ] 每天回覆的數量合理（預設每品牌每天最多 6 則草稿）。
- [ ] 對方回「不需要」就停止，不追著推銷。
- [ ] 用官方 API 時，只申請用得到的權限，並如實說明用途。

## 《個人資料保護法》檢查表

公開貼文的帳號名稱、內容仍可能屬於個人資料。原則上：

- [ ] **蒐集目的明確**：只為了「回覆對方公開提出的需求」。
- [ ] **最少蒐集**：本工具只存帳號、內文、連結、時間、互動數；不要另外收集電話、地址、照片。
- [ ] **限期保存**：`retention_days`（預設 60 天）到期自動刪除；匯出的 CSV 用完請刪掉。
- [ ] **不做他用**：不把名單賣給別人、不拿來做與當初目的無關的行銷。
- [ ] **資料放在你自己電腦**：`data/` 不要上傳到公開的雲端資料夾或 git。
- [ ] 對方要求刪除時，請從資料庫刪除相關資料。

## 廣告用語檢查表

品質檢查會對下列用語標警告，原則上請不要用在留言裡：

| 類型 | 例子 | 可能涉及 |
|---|---|---|
| 誇大、絕對用語 | 保證、百分之百、全台最、第一名、最便宜 | 《公平交易法》不實廣告 |
| 醫療效能（美業） | 治療、根治、消炎 | 化粧品、醫療相關廣告規範 |
| 保證結果（補教） | 保證上榜、包過 | 不實廣告、消費爭議 |
| 投資獲利（房仲） | 保證增值、穩賺 | 不動產相關廣告規範 |

房仲業：不動產經紀業的廣告與招攬，原則上要註明經紀業名稱（《不動產經紀業管理條例》第 21 條）。請在品牌帳號的個人簡介或回覆中依規定揭露。

## 帳號風險

就算完全人工回覆，短時間大量留言、內容重複，帳號仍可能被平台限制。建議：

- 一開始每天 1–3 則，觀察一兩週。
- 模板至少準備 5 則以上不同寫法，並常常改寫（系統會避開 7 天內用過的同一句）。
- 被退回的草稿一定填原因，讓系統少用不好的寫法。
