# 金鑰申請與設定教學（tw-social-radar）

**只跑示範、或只用「匯入檔案＋模板」：不需要任何金鑰。** 下面每一項都是「用到那個功能才要申請」。

| 項目 | 什麼時候需要 | 去哪裡拿 | 費用 | 填在 `.env` |
|---|---|---|---|---|
| Threads API 存取權杖 | `source.type: threads_api`（官方關鍵字搜尋）、自動發文外掛 | Meta for Developers | 免費（有查詢／發文次數上限） | `THREADS_ACCESS_TOKEN` |
| Threads 使用者 ID | 只有自動發文外掛 | 用權杖查一次 | 免費 | `THREADS_USER_ID` |
| Anthropic（Claude）API 金鑰 | `llm.provider: claude_api` | Claude Console | 依用量計費 | `ANTHROPIC_API_KEY` |
| Claude Code 登入 | `llm.provider: claude_cli` | 安裝 Claude Code 後登入 | 用你的 Claude 訂閱額度 | （不用填） |
| Ollama | `llm.provider: ollama` | 安裝 Ollama | 免費 | （不用填） |
| LINE Channel access token＋收件 ID | `notify.line: true` | LINE Developers Console | 免費方案有每月則數上限 | `LINE_CHANNEL_ACCESS_TOKEN`、`LINE_TO_ID` |
| Discord Webhook 網址 | `notify.discord: true` | Discord 頻道設定 | 免費 | `DISCORD_WEBHOOK_URL` |
| 審核頁密碼 | 審核頁要給手機或其他電腦連 | **自己想一組** | 免費 | `RADAR_REVIEW_PASSWORD` |

---

## 先做一次：建立 `.env` 檔

1. 在專案資料夾把 **`.env.example`** 複製一份，檔名改成 **`.env`**（Windows 看不到副檔名：檔案總管 →「檢視」→ 勾「副檔名」）。
2. 用記事本打開，把下面拿到的值貼在等號後面，**不要加引號、不要有空格**，存檔。
3. 執行 `python -m radar doctor`，確認沒有 ❌。

> 🔒 `.env` 已經在 `.gitignore` 裡，不會被 git 上傳。**不要把 `.env` 的內容貼到聊天室、Issue、截圖，也不要寫進 `settings.yaml` 或程式碼裡。** 不小心外流就立刻到發放的地方「撤銷／重新產生」。

## 一、Threads API 存取權杖（官方關鍵字搜尋）

> 原則上以 [Meta 官方 Threads API 文件](https://developers.facebook.com/docs/threads) 為準，後台介面可能會改版。

### 1. 建立 Meta 開發者帳號與 App

1. 打開 [Meta for Developers](https://developers.facebook.com/)，用 Facebook 帳號登入，第一次會要你註冊成開發者（驗證手機或信用卡其中之一）。
2. 右上角「我的應用程式」→「建立應用程式」。
3. 「使用案例」選 **「存取 Threads API」（Access the Threads API）**，填 App 名稱（例如「我的社群雷達」）和聯絡 Email，建立。

### 2. 開權限

1. 進到 App 後台 →「使用案例」→ Threads API 的「自訂」。
2. 在「權限」勾選：
   - `threads_basic`（一定要）
   - `threads_keyword_search`（關鍵字搜尋）
   - 要用自動發文外掛才勾：`threads_content_publish`、`threads_manage_replies`

### 3. 把自己的 Threads 帳號加成測試人員

1. App 後台 →「應用程式角色」→「角色」→ 新增「Threads 測試人員」，輸入你的 Threads 帳號。
2. 到 **Threads App** →「設定」→「帳號」→「網站權限」→「邀請」，接受邀請。

### 4. 產生權杖

1. App 後台 → Threads API 使用案例 →「設定」→ 找到 **「使用者權杖產生器」（User Token Generator）**，對你的測試帳號按「產生權杖」。
2. 產生的是**短效權杖**（約 1 小時）。換成**長效權杖**（約 60 天）：

   ```bash
   curl "https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret=你的App密鑰&access_token=短效權杖"
   ```

   App 密鑰在 App 後台「應用程式設定」→「基本資料」→「應用程式密鑰」。
3. 把回傳的 `access_token` 貼到 `.env`：

   ```
   THREADS_ACCESS_TOKEN=（貼上長效權杖）
   ```

4. 長效權杖到期前要續期（建議每月一次）：

   ```bash
   curl "https://graph.threads.net/refresh_access_token?grant_type=th_refresh_token&access_token=目前的長效權杖"
   ```

### 5. 送審（要搜「別人」的公開貼文才需要）

- ⚠️ **還沒通過 Meta 審查前，關鍵字搜尋原則上只會回傳「你自己帳號」的貼文**，雷達會找不到潛在客人。
- 要搜公開貼文：App 後台 →「審查」→ 申請 `threads_keyword_search` 的進階存取。通常要準備：隱私權政策網址、使用說明、示範影片（錄一段「搜尋 → 審核 → 人工回覆」的操作）。
- 送審時誠實說明用途：「協助在地商家找出公開詢問相關服務的貼文，由人工審核後回覆」。不要申請用不到的權限。
- 還沒通過前，可以先用 `source.type: file`（匯入檔案）來用。

### 6. 設定

`config/settings.yaml`：

```yaml
source:
  type: threads_api
  threads_api:
    search_type: RECENT
    max_queries_per_run: 8
```

### 費用與限制

- 免費。
- 官方對每個使用者有**每 24 小時的查詢次數上限**（同一個帳號跨所有 App 合計），沒有結果的查詢不算。本工具每輪只查 `max_queries_per_run` 個關鍵字、輪流查，一般小店每 30–60 分鐘跑一次不會超過。
- 敏感或冒犯性的關鍵字，官方會回傳空結果。

### 安全注意

- 權杖等於可以用你的 Threads 帳號讀資料（勾了發文權限的話還能發文），**當密碼看待**。
- 只勾用得到的權限。不用自動發文，就不要勾 `threads_content_publish`、`threads_manage_replies`。
- 懷疑外流：App 後台重設 App 密鑰，並重新產生權杖。

## 二、Threads 使用者 ID（只有自動發文外掛需要）

有了權杖後查一次：

```bash
curl "https://graph.threads.net/v1.0/me?fields=id,username&access_token=你的權杖"
```

把回傳的 `id` 填到 `.env`：

```
THREADS_USER_ID=（貼上）
```

## 三、Anthropic（Claude）API 金鑰

用在 `llm.provider: claude_api`：讓 AI 依品牌口吻寫草稿（`draft_mode: llm`）或判斷需求強度（`classify: true`）。

1. 打開 [Claude Console](https://console.anthropic.com/)，註冊並登入。
2. 「Billing」先儲值或綁信用卡（API 是**用多少付多少**，跟 Claude 網頁版的訂閱是分開的）。
3. 「API Keys」→「Create Key」，取個名字（例如 social-radar），複製（**只會顯示一次**）。
4. 填到 `.env`：

   ```
   ANTHROPIC_API_KEY=（貼上）
   ```

5. `config/settings.yaml`：

   ```yaml
   llm:
     provider: claude_api
     draft_mode: llm
     claude_api:
       model: claude-haiku-5-5
   ```

**費用**：依模型與字數計費，價格以 [官方價目表](https://www.anthropic.com/pricing) 為準。每則草稿只送一則貼文和品牌設定，用小模型（Haiku）一般每天幾則的量費用很低。建議在 Console 的「Limits」設**每月花費上限**。

**安全注意**：金鑰外流別人就能用你的額度。不要寫進程式或 yaml；外流立刻到 Console 刪掉那把金鑰再建新的。

## 四、Claude Code（`llm.provider: claude_cli`，不用金鑰）

已經有 Claude 訂閱（Pro／Max）的人可以用這個，不用另外申請 API 金鑰。

1. 依 [Claude Code 官方說明](https://docs.claude.com/en/docs/claude-code) 安裝。
2. 在終端機執行 `claude`，照畫面登入一次。
3. 確認 `claude --version` 有輸出。
4. `config/settings.yaml` 設 `llm.provider: claude_cli`。

**費用**：用你的訂閱額度，額度用完要等重置。Windows 上程式會用「不開視窗」的方式呼叫，不會跳出黑色視窗。

## 五、Ollama（本機模型，不用金鑰）

貼文完全不離開你的電腦。

1. 到 [ollama.com](https://ollama.com/) 下載安裝。
2. 下載一個中文能力不錯的模型，例如：

   ```bash
   ollama pull qwen2.5:7b
   ```

3. `config/settings.yaml`：

   ```yaml
   llm:
     provider: ollama
     ollama:
       host: http://127.0.0.1:11434
       model: qwen2.5:7b
   ```

**費用**：免費，但需要電腦夠力（7B 模型建議 8GB 以上記憶體），寫出來的中文品質依模型而定，請先多審幾則再決定。

## 六、LINE 通知（`notify.line: true`）

有新草稿時推一則 LINE 訊息給你。

### 1. 建立官方帳號並開 Messaging API

1. 打開 [LINE Official Account Manager](https://manager.line.biz/)，建立一個官方帳號（可以只給自己用）。
2. 官方帳號後台 →「設定」→「Messaging API」→「啟用 Messaging API」，選或建立 Provider。

### 2. 拿 Channel access token

1. 打開 [LINE Developers Console](https://developers.line.biz/console/) → 你的 Provider → 這個 channel。
2. 「Messaging API」分頁最下面「Channel access token (long-lived)」→「Issue」→ 複製。

```
LINE_CHANNEL_ACCESS_TOKEN=（貼上）
```

### 3. 拿收件人 ID（你自己的 userId）

1. 同一個 channel 的「Basic settings」分頁，最下面「Your user ID」（U 開頭的一串）→ 複製。
2. 用手機加這個官方帳號為好友（不加好友收不到推播）。

```
LINE_TO_ID=（貼上）
```

**費用**：推播（push）會算進官方帳號的每月訊息則數；免費方案有每月則數上限，超過要升級方案，以 [LINE 官方方案說明](https://tw.linebiz.com/) 為準。本工具每輪只合併成一則通知。

**安全注意**：Channel access token 等於整個官方帳號的發訊權，外流就到 Developers Console 重新 Issue（舊的會失效）。

## 七、Discord 通知（`notify.discord: true`）

1. Discord 伺服器 → 要收通知的頻道 → ⚙️「編輯頻道」→「整合」→「Webhook」→「新 Webhook」。
2. 「複製 Webhook 網址」。

```
DISCORD_WEBHOOK_URL=（貼上）
```

**費用**：免費。**安全注意**：拿到網址的人都能在那個頻道發訊息，外流就把 Webhook 刪掉重建。

## 八、審核頁密碼（`RADAR_REVIEW_PASSWORD`）

審核頁預設只聽本機（127.0.0.1），自己電腦用不需要密碼。

要給手機或其他電腦連：

1. 自己想一組夠長的密碼（建議 16 字以上，混合英數）。
2. 填到 `.env`：

   ```
   RADAR_REVIEW_PASSWORD=（你的密碼）
   ```

3. `config/settings.yaml` 的 `review.host` 改成 `0.0.0.0`。沒設密碼程式會拒絕啟動。
4. 瀏覽器會跳出登入框：帳號隨便填，密碼填上面那組。

**安全注意**：這是 HTTP Basic 認證，密碼在區網裡是明文傳送。**要從外網連，請一定透過 HTTPS 通道**（例如 Cloudflare Tunnel 或反向代理），不要直接開路由器的連接埠。

## 九、審核帳號（多人審核，不用申請）

公司有新成員、或幫客戶代管品牌時用：

1. 先設好管理員密碼 `RADAR_REVIEW_PASSWORD`（上一節）。管理員登入時帳號填 `admin`。
2. 開帳號（會要你輸入兩次密碼，至少 10 字，畫面不會顯示）：

   ```bash
   python -m radar user add amy --brands myshop,client-a
   ```

3. 密碼只存雜湊在 `data/reviewers.json`（不會進 git）。忘記密碼就用同一個指令重設。
4. 透過網域（例如 Cloudflare Tunnel）連審核頁時，把網域加進 `config/settings.yaml` 的 `review.allowed_hosts`，否則會看到「Host 不允許」。

**安全注意**：每個人用自己的帳號，不要共用管理員密碼；離職當天 `python -m radar user remove 名字`。

## 疑難排解

| 狀況 | 怎麼辦 |
|---|---|
| `doctor` 說缺某個金鑰 | `.env` 檔名對嗎（不是 `.env.txt`）？等號後面有沒有多空格或引號？ |
| Threads API 回 HTTP 400／190 | 權杖過期或貼錯；重新產生長效權杖 |
| 關鍵字搜尋只找到自己的貼文 | App 還沒通過 `threads_keyword_search` 審查，見上面第一節第 5 點 |
| Claude API 回 401 | 金鑰錯；回 429 是用量或速率上限；回 400 看訊息裡的 model 名稱是否正確 |
| Ollama 連不上 | Ollama 有沒有在跑？`ollama list` 看模型是否已下載 |
| LINE 沒收到 | 有沒有加官方帳號好友？`LINE_TO_ID` 是不是 U 開頭那串？ |
| 權杖過期一直收到通知？ | 同一種錯誤一天只通知一次；換好權杖後下一輪自動恢復 |
| 審核頁顯示「Host 不允許」 | 把你用的網域加進 `review.allowed_hosts` |
| 審核頁顯示「登入失敗太多次」 | 等 10 分鐘；忘記密碼請管理員重設 |
